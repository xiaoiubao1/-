# 随心记 v1.3.0 开发清单

目标：把桌面小组件升级为可 DIY 的个性化组件，并把课程表压缩为更适合“一眼看完本周”的紧凑周视图，同时统一 APP 图标。

## 1. 桌面小组件 DIY

- [x] 增加小组件个性化设置区
- [x] 支持纯色背景
- [x] 支持用户从手机选择自定义背景图片
- [x] 支持背景透明度调节
- [x] 支持文字颜色自定义（浅色 / 深色 / 自动对比）
- [x] 支持强调色选择
- [x] 支持半透明磨砂效果模拟
- [x] 修改后立即刷新所有已添加的小组件
- [x] 保留“下一条待办 + 今天下一节课”信息
- [x] 兼容 Android 桌面小组件缩放

> 说明：经典 Android RemoteViews 无法在所有桌面上实现真正的实时系统级背景模糊，因此采用“自定义图片 + 半透明叠层 + 透明度/颜色调节”的稳定兼容方案，视觉上接近毛玻璃。

## 2. APP 图标统一

- [x] 删除 APP 内“自定义 APP 图标”入口
- [x] 删除日历 / 清单 / 方格 / 便签四套 activity-alias 图标切换
- [x] 使用用户提供的灰发蓝眼草帽角色图片裁剪生成唯一正式图标
- [x] MainActivity 直接作为 Launcher 入口
- [x] 保持 applicationId 不变，不影响正式签名覆盖升级

## 3. 课程表紧凑周视图

- [x] 周一到周日全部保持在同一屏宽度内
- [x] 8 个课节尽量在一屏纵向展示
- [x] 缩小节次栏、表头和课程块留白
- [x] 课程格显示课程名，空间允许时显示地点
- [x] 当前日期 / 当前星期高亮
- [x] 点击空白格直接按对应星期和节次添加课程
- [x] 点击已有课程进入编辑
- [x] 保留课程提醒
