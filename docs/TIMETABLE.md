# 课表与教务导入

## 使用

1. 课表顶部可切换或新建学期；右上角调节按钮设置第一周的周一、总周数和每日作息。
2. 旧数据迁移到「原有课表 · 每周重复」，在填写学期日期前仍每周显示、每周提醒，避免猜测开学日期。
3. 课程编辑支持选择任意上课周，输入示例：`1-16`、`1-16(单)`、`1,3,8-12`。同一课程不同地点或不同时间应分开添加。
4. 课程保存绝对钟点。修改作息不会移动已有课程；修改课程时可选择新的快捷节次，再调整结束时间跨节上课。
5. 仅当前选中的学期发送课程提醒。学期结束或本周不上课时不发送提醒。系统未允许准时提醒时仍可能延迟。

## 导入方式

采用与 WakeUp 公开说明类似的交互：在应用中访问教务系统，由本人登录并打开学期课表，再提取课程、预览和确认。此项目独立实现通用解析，没有接入 WakeUp 私有 API 或复制其应用源码。

- 教务网站：输入 HTTPS 网址，登录后打开含周次的完整学期课表，点击识别。只提取可访问页面的表格，不读取表单密码或 Cookie。跨域框架无法读取时会提示；可打开课表独立地址或导出 HTML。
- HTML：可读取带编码声明的保存网页。支持明确周次的课程列表，以及有星期表头、节次行头的网格；合并节次和独立课程块可解析。若结构不同或缺少周次，拒绝猜测并提示专用适配。
- CSV：UTF-8，可带 BOM，支持引号、逗号、跨行备注。表头支持中文或英文。

推荐 CSV 表头：

```csv
name,teacher,location,day,startTime,endTime,weeks,note
高等数学,张老师,A101,1,08:30,10:10,1-16(单),每隔一周
大学英语,李老师,B202,2,14:30,16:10,"1,3,8-12",请带课本
```

也可使用中文表头「课程名称、教师、教室、星期、开始时间、结束时间、周次、备注」。以「节次」替代起止时间时，先设置学校作息。限制：单文件 2 MiB、最多 2000 条安排。

预览会显示跳过行、重复和潜在时间冲突。网页 / HTML 仅可追加，不提供覆盖；如需重建请先创建新学期。只有完整识别且无跳过行的课程 CSV 在确认后可替换。覆盖仅针对选择的学期，不影响记录或其他学期。所有记录先校验，再在数据库事务中写入。导入课程默认关闭提醒。

课程 CSV 不包含学期起始日或作息设置；迁移整套数据请使用完整备份。备份格式 v4 包含多个学期、所有节次、课程周次和当前学期，仍支持 v1–3 的旧备份。新版备份不能在不支持 v4 的旧应用恢复。

## 隐私与兼容边界

新增网络权限仅供用户主动打开教务网页。本应用不提供收集学校账号、密码、课表的服务器。禁止明文 HTTP、证书错误放行、文件和内容 URI 访问；不设置 JavascriptInterface，关闭时清理 Cookie、缓存和网页存储。应用不支持弹出新窗口、外部 App 登录跳转、第三方 Cookie，部分统一认证流程可能不兼容。进程被杀后残留的 WebView Cookie 会在下次进入网页导入前清理。

未取得具体学校网址和课表样本前，不能承诺该学校已适配。单元测试使用构造的列表、单双周和合并表格样本；需要在真实设备、学校网站、校园网环境进一步核对登录、缺课、周次和提醒。
