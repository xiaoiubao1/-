# 随心记（Android）

一个以 **随手记录 + 紧凑周课表 + 提醒 + 本地备份 + 桌面小组件** 为核心的原生 Android 应用。当前版本 **v1.3.1**。

## v1.3.1 优化

- ⏱️ **全新时间选择**：不再调用 Android 原生 `DatePickerDialog / TimePickerDialog`
- ⚡ **快捷日期**：今天、明天、后天和近 10 天可以直接点选，远期日期可展开 Compose Material 3 日历
- 🕐 **快捷时间**：常用时间一键选择，也可按小时 + 5 分钟粒度精确选择
- 📚 **课程时间更快**：1～8 节课可以直接套用标准时间，开始/结束时间仍支持自定义
- 🪟 **更通透的玻璃层**：有自定义壁纸时，内容卡片约为 16%～28% 不透明度，减少白色遮挡
- 🌫️ **轻雾化背景**：降低壁纸模糊和白色覆盖，不再把背景“洗白”
- 🧭 **透明底部导航**：取消默认 Material NavigationBar 的高不透明背景，改用约 10% 的自绘透明层
- 📱 **Edge-to-edge**：状态栏和系统导航栏改为透明，Android 10+ 关闭导航栏强制对比底色
- 🔢 **版本**：versionCode 5 / versionName 1.3.1

## v1.3.0 新增

- 🧩 **桌面小组件 DIY**：可自选背景图片、背景色、文字颜色模式、强调色、透明度与磨砂覆盖
- 🔄 **小组件即时刷新**：修改 DIY 设置后，桌面上已添加的小组件会立即刷新
- 📅 **一屏周课表**：周一到周日与 1～8 节课压缩在同一屏内，无需横向滑动即可快速扫完整周
- 🎨 **课程色块**：课程名称以紧凑色块显示，空间允许时同时显示教室
- ➕ **格子直达编辑**：点击课表空白格按对应星期/课节添加课程，点击已有课程进入编辑
- 🖼️ **统一 APP 图标**：使用用户指定的灰发蓝眼草帽角色裁剪图作为唯一启动图标
- 💾 **备份增强**：`.suixinji` 完整备份同时保存小组件 DIY 设置和可读取的小组件背景图片

> Android 经典 RemoteViews 小组件无法在所有品牌桌面上提供真正的系统级实时背景模糊，因此桌面小组件仍采用“自定义图片 + 半透明叠层 + 颜色/透明度控制”的兼容方案；APP 本体则使用更低不透明度的 Compose 玻璃层。

## 桌面小组件 DIY

进入 **我的 → 桌面小组件 DIY**：

- 选择或移除小组件背景图片
- 选择背景颜色
- 文字颜色：自动 / 深色 / 浅色
- 选择强调色
- 调整背景透明度
- 开关磨砂覆盖

桌面添加方式：长按桌面空白处 → **小组件** → **随心记** → **随心记概览**。

## 紧凑周课表

课表页固定展示 **周一～周日 × 1～8 节**。课程名称最多两行，点击空白格新增课程，点击已有课程进入编辑。v1.3.1 的课程编辑页还增加了 **1～8 节标准时间快捷套用**。

## 数据导出与完整备份

进入 **我的 → 数据**：

- **导入**：CSV、JSON、TXT
- **CSV**：导出全部随心记记录
- **备份**：生成 `.suixinji` 完整备份
- **恢复**：覆盖恢复记录、课程、主题、背景、小组件 DIY 设置和可读取图片，并重新建立提醒

## 正式签名与覆盖升级

Android 覆盖安装要求包名相同，并且新旧 APK 使用同一套正式签名密钥。正式签名材料只通过 GitHub Actions Secret `ANDROID_SIGNING_BUNDLE` 注入，公开仓库不保存私钥。

详细说明见 [`docs/SIGNING.md`](docs/SIGNING.md)。

## 下载最新版 APK

网站可以长期使用固定地址：

```text
https://github.com/xiaoiubao1/-/releases/latest/download/suixinji.apk
```

`main` 更新后会自动构建正式 Release APK、执行 `apksigner verify`，并创建新的 GitHub Release。

## 数据位置

- 记录与课程：应用私有 SQLite 数据库 `suixinji.db`
- 个性化设置：应用私有 SharedPreferences
- 恢复的图片：应用私有 `filesDir/restored_media`

卸载应用会清除本地数据，建议定期创建 `.suixinji` 备份并保存到其他位置。
