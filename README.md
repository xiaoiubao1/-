# 随心记（Android）

一个以“随手记录 + 周课程表 + 提醒 + 本地备份”为核心的原生 Android 应用。当前开发版本 **v1.2.0** 已加入固定正式签名、完整备份恢复、CSV 导出、课程开始提醒，以及重新设计的课程表与个性化界面。

## v1.2.0 新增

- 🔐 **固定正式签名**：正式 APK 使用同一套私有签名密钥，后续版本可直接覆盖升级，无需每次卸载
- 🛡️ **签名保护**：签名材料只从 GitHub Actions Secret `ANDROID_SIGNING_BUNDLE` 读取，公开仓库不保存私钥
- 📤 **CSV 导出**：可将全部随心记记录导出为 CSV
- 💾 **完整备份**：生成 `.suixinji` 文件，包含记录、课程、个性化设置以及能够读取到的图片附件
- ♻️ **备份恢复**：恢复后自动重新安排事件提醒和课程提醒
- 🔔 **课程提醒**：每门课程可选择上课时或提前 5 / 10 / 15 / 30 / 60 分钟提醒
- 🔗 **课程通知直达**：点击课程通知直接进入对应课程编辑页
- 🗃️ **数据库 v3**：保留旧数据并增加课程提醒字段

## 新版界面

- 📅 **周课表网格**：按周一到周日 + 8 个课节直观展示课程；点击空白课节可以直接添加该星期/该时间的课程
- 🧭 **三标签底部导航**：`课表 / 随心记 / 我的`，取消中间大型悬浮加号
- ☀️ **默认浅色背景** 与 🩶 **灰色背景**：应用不再内置角色壁纸或固定装饰壁纸
- 🖼️ **自定义背景开关**：用户主动开启后才能选择自己的图片作为应用背景
- 🫧 **毛玻璃强度**：可调整背景模糊与卡片磨砂透明感
- 🎨 **主题强调色**：蓝色、紫色、青色、粉色、橙色
- 📱 **可切换 APP 启动图标**：日历、清单、方格、便签 4 种启动器图标；使用 Android `activity-alias` 实现，不修改应用包名
- 🧹 **移除旧资源**：旧 Q 版 APP 图标和 Q 版内置壁纸已从源码删除

> Android 启动器并没有一个所有品牌都支持的“把任意相册图片直接变成应用图标”的标准接口，因此当前采用系统兼容性更好的多 `activity-alias` 图标切换方案。不同桌面刷新图标可能需要几秒钟。

## 数据导出与完整备份

进入 **我的 → 导入 / 导出数据**：

- **导入文件**：继续支持 CSV、JSON、TXT
- **导出 CSV**：方便在 Excel、WPS 等表格软件查看记录
- **完整备份**：生成 `.suixinji` 文件
- **恢复备份**：覆盖当前数据后恢复记录、课程、主题、背景设置、毛玻璃强度、图标样式和可读取的图片，并重建提醒

若某个外部图片 URI 已失效，该图片可能无法放入备份，但其他数据仍可正常保存。

## 课程提醒

编辑课程时打开 **课程开始提醒**，可以选择：上课时、提前 5、10、15、30 或 60 分钟。

课程提醒使用 WorkManager 安排下一次课程通知，通知执行后会自动安排下一周。Android 的省电策略可能带来少量延迟，因此属于可靠的“附近时间提醒”，不是秒级闹钟。

## 正式签名与覆盖升级

Android 覆盖安装要求 **applicationId（包名）相同，并且新旧 APK 使用同一签名密钥**。因此固定私钥不是可选项：私钥负责给 APK 签名，系统用对应签名信息验证新版是否有权覆盖旧版。

正式签名配置见 [`docs/SIGNING.md`](docs/SIGNING.md)。仓库本身不会保存 `.jks` 私钥。主分支只有在仓库已配置 `ANDROID_SIGNING_BUNDLE` Secret 后才会发布正式 APK；缺少 Secret 会主动停止发布，避免错误签名破坏以后覆盖升级。

## 直接下载最新版 APK

网站可以长期使用固定地址：

```text
https://github.com/xiaoiubao1/-/releases/latest/download/suixinji.apk
```

正式签名 Secret 配置完成并合并 v1.2.0 后，后续 `main` 更新会自动构建签名 Release APK、执行 `apksigner verify`，然后创建新的 GitHub Release。

## 数据位置

- 事件、课程：应用私有 SQLite 数据库 `suixinji.db`
- 个性化偏好：应用私有 SharedPreferences
- 从备份恢复的图片：应用私有 `filesDir/restored_media`
- 卸载应用会清除本地数据，因此建议定期创建 `.suixinji` 备份并保存到其他位置
