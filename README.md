# 随心记（Android）

一个以 **随手记录 + 紧凑周课表 + 提醒 + 本地备份 + 桌面小组件** 为核心的原生 Android 应用。当前版本 **v1.3.0**。

## v1.3.0 新增

- 🧩 **桌面小组件 DIY**：可自选背景图片、背景色、文字颜色模式、强调色、透明度与磨砂覆盖
- 🔄 **小组件即时刷新**：修改 DIY 设置后，桌面上已添加的小组件会立即刷新
- 📅 **一屏周课表**：周一到周日与 1～8 节课压缩在同一屏内，无需横向滑动即可快速扫完整周
- 🎨 **课程色块**：课程名称以紧凑色块显示，空间允许时同时显示教室
- ➕ **格子直达编辑**：点击课表空白格按对应星期/课节添加课程，点击已有课程进入编辑
- 🖼️ **统一 APP 图标**：移除旧的日历/清单/方格/便签图标切换，使用用户指定的灰发蓝眼草帽角色裁剪图作为唯一启动图标
- 💾 **备份增强**：`.suixinji` 完整备份现在同时保存小组件 DIY 设置和可读取的小组件背景图片
- 🔢 **版本**：versionCode 4 / versionName 1.3.0

> Android 经典 RemoteViews 小组件无法在所有品牌桌面上提供真正的系统级实时背景模糊，因此随心记采用“自定义图片 + 半透明叠层 + 颜色/透明度控制”的兼容方案来模拟毛玻璃效果。

## 已有功能

- 📝 记录标题、内容、地点、时间与图片
- 🔎 搜索标题 / 内容 / 地点，筛选全部 / 待办 / 已完成
- 🔔 事件提醒、通知测试
- 📚 周课程表，课程老师 / 教室 / 备注
- ⏰ 课程开始提醒：上课时或提前 5 / 10 / 15 / 30 / 60 分钟
- 📥 CSV / JSON / TXT 导入
- 📤 CSV 导出
- 💾 `.suixinji` 完整备份与恢复
- ☀️ 浅色 / 🩶 灰色默认背景
- 🖼️ 用户主动开启后可选择自定义 APP 背景
- 🫧 可调应用毛玻璃强度
- 🔒 SQLite 本地存储，无账号、无服务器依赖

## 桌面小组件 DIY

进入 **我的 → 桌面小组件 DIY**：

- 选择或移除小组件背景图片
- 选择背景颜色
- 文字颜色：自动 / 深色 / 浅色
- 选择强调色
- 调整背景透明度
- 开关磨砂覆盖

桌面添加方式：长按桌面空白处 → **小组件** → **随心记** → **随心记概览**。

## 紧凑周课表

课表页固定展示 **周一～周日 × 1～8 节**。新版取消原先为适配宽度而设计的横向滚动，优先保证手机上一眼看到整周课程；课程名称最多两行，点击色块查看完整信息。

## 数据导出与完整备份

进入 **我的 → 数据**：

- **导入**：CSV、JSON、TXT
- **CSV**：导出全部随心记记录
- **备份**：生成 `.suixinji` 完整备份
- **恢复**：覆盖恢复记录、课程、主题、背景、小组件 DIY 设置和可读取图片，并重新建立提醒

## 正式签名与覆盖升级

Android 覆盖安装要求包名相同，并且新旧 APK 使用同一套正式签名密钥。正式签名材料只通过 GitHub Actions Secret `ANDROID_SIGNING_BUNDLE` 注入，公开仓库不保存私钥。

详细说明见 [`docs/SIGNING.md`](docs/SIGNING.md)。

## 下载最新版 APK

网站可以长期使用固定地址：

```text
https://github.com/xiaoiubao1/-/releases/latest/download/suixinji.apk
```

`main` 更新后会自动构建正式 Release APK、执行 `apksigner verify`，并创建新的 GitHub Release。

## 数据位置

- 记录与课程：应用私有 SQLite 数据库 `suixinji.db`
- 个性化设置：应用私有 SharedPreferences
- 恢复的图片：应用私有 `filesDir/restored_media`

卸载应用会清除本地数据，建议定期创建 `.suixinji` 备份并保存到其他位置。
